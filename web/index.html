📚 Academic Theory & Viva Guide: Module 5 NP-Completeness & Approximation Expand ▾

1. Optimization Problem vs. Decision Problem

In complexity theory, an optimization problem seeks the maximum value subset subject to ∑ time ≤ Budget. Its decision problem asks: "Can priority ≥ K be achieved within budget W?" The decision problem is NP-complete via polynomial reduction from SUBSET-SUM.

2. Why Approximation is Necessary

Standard Dynamic Programming runs in O(n × W) time, which is pseudo-polynomial. For large budgets or real-time web responsiveness, exact algorithms can become bottlenecked. The greedy density heuristic runs in polynomial time O(n log n) with minimal memory O(n).

3. The 1/2-Approximation Mathematical Proof

Sorting by density v_i/w_i packs the continuous (fractional) knapsack optimum: V(GreedyPrefix) + v_{first_rejected} ≥ OPT_{fractional} ≥ OPT. Comparing the greedy prefix against the single highest-value feasible item guarantees: max(V(GreedyPrefix), v_{max}) ≥ 0.5 × OPT.

About This Project

Digital Library Search System — a DSA project implementing six algorithms on a 100-document corpus.

Architecture

The website is the presentation layer. Java remains the algorithm layer. Browser JavaScript sends requests to the Java backend, the Java backend executes the existing algorithms against the corpus, and the results are returned as JSON for display.
