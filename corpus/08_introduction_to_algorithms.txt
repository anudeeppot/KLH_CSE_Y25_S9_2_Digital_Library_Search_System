Content: CHAPTER 1: FORMAL FOUNDATIONS OF STRINGOLOGY AND COMPUTATION
In theoretical computer science and digital library engineering, stringology is the branch of algorithmic design dedicated to strings and sequences. Formally, an alphabet Sigma is a finite, non-empty set of symbols. A string S of length N over Sigma is an ordered sequence of characters S[0 .. N - 1]. The empty string is denoted epsilon with length 0.
The concatenation of two strings X and Y, denoted XY, has length |X| + |Y|. A string W is a substring of S if there exist strings X and Y such that S = XWY. If X = epsilon, W is a prefix of S. If Y = epsilon, W is a suffix of S.
The central computational challenge in academic libraries is indexing millions of text characters such that queries can be evaluated without scanning the entire library corpus sequentially.

CHAPTER 2: STRING MATCHING AUTOMATA
A string matching automaton is a Deterministic Finite Automaton (DFA) constructed specifically to recognize occurrences of a pattern P in an arbitrary input text T.
Formally, a DFA is a 5-tuple (Q, q_0, A, Sigma, delta):
- Q = {0, 1, ..., M} is the finite set of states, where each state represents the length of the longest prefix of P matched so far.
- q_0 = 0 is the start state.
- A = {M} is the set of accepting states (matching pattern P).
- Sigma is the input alphabet.
- delta: Q x Sigma -> Q is the state transition function.

Definition 2.1 (The Suffix Function sigma_P):
For any string X over Sigma, the suffix function sigma_P(X) is defined as:
sigma_P(X) = max { k : P[0 .. k - 1] is a suffix of X }.
The transition function delta is then defined as:
delta(q, a) = sigma_P( P[0 .. q - 1] a ).
Execution:
Once the transition table delta is precomputed, searching for pattern P in text T of length N requires only:
q = 0
for i = 0 to N - 1:
    q = delta(q, T[i])
    if q == M:
        report match at index i - M + 1.
The search time is strictly Theta(N) character lookups, with exactly one transition per text character and zero rollbacks.

CHAPTER 3: TRIES AND COMPACT PATRICIA TREES
When indexing large vocabularies of academic terms and book metadata, standard hash tables do not support prefix queries, range searches, or nearest-neighbor queries.
Definition 3.1 (The Retrieval Tree or Trie):
A Trie is a rooted tree where:
1. Each node (except the root) is associated with a character from Sigma.
2. The path from the root to any node spells out a prefix of one or more indexed terms.
3. Terminal nodes carry a boolean flag indicating the end of a valid vocabulary word.
While standard tries allow search in O(M) time, they consume significant memory when keys have long unique branches.
Definition 3.2 (The Patricia Trie):
A Practical Algorithm to Retrieve Information Coded in Alphanumeric (PATRICIA) tree compresses linear unary chains of single-child nodes into single composite edges labeled with substring segments or skip counters. This guarantees that every internal node has at least two children, bounding the total number of nodes to at most 2K - 1 for K indexed words.

CHAPTER 4: AMORTIZED ANALYSIS VIA THE POTENTIAL METHOD
In evaluating complex string algorithms like KMP, Boyer-Moore, and Suffix Automata, individual operations may take variable amounts of time. Simple worst-case per-operation bounds fail to reflect true performance.
Amortized analysis guarantees the average performance of each operation over a worst-case sequence of operations.
The Potential Method (Physicist's Method):
Let D_0 be the initial data structure state, and D_i be the state after operation i.
Let Phi: D -> R be a potential function mapping data structure states to real numbers, such that Phi(D_i) >= Phi(D_0) for all i.
The amortized cost a_i of operation i with actual cost c_i is defined as:
a_i = c_i + Phi(D_i) - Phi(D_{i-1})
Summing across a sequence of n operations:
sum_{i=1}^n a_i = sum_{i=1}^n c_i + Phi(D_n) - Phi(D_0)
Because Phi(D_n) >= Phi(D_0), the total actual cost is strictly bounded by the total amortized cost:
sum_{i=1}^n c_i <= sum_{i=1}^n a_i.
In KMP, defining Phi = j ensures that decreases in pattern pointer j pay for the character comparisons, proving the O(N) aggregate time bound.
