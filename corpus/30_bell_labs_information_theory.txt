Content: CHAPTER 1: THE FOUNDATIONAL MEASURE OF INFORMATION
In 1948, Claude Elwood Shannon published 'A Mathematical Theory of Communication' in the Bell System Technical Journal, establishing the mathematical foundations of modern digital telecommunications, computer science, and data retrieval.
Prior to Shannon, information was considered a qualitative, subjective concept. Shannon demonstrated that information can be quantified with mathematical precision as the resolution of uncertainty.
When a user searches an academic digital library, both the query string Q and the document corpus D are discrete information sources. The statistical distribution of characters, words, and syntactic structures dictates the computational difficulty of string matching and inverted index compression.

CHAPTER 2: MATHEMATICAL DERIVATION OF SHANNON ENTROPY
Definition 2.1 (The Information Content of an Event):
Let E be an event with probability of occurrence P(E).
The self-information (or surprise) associated with observing E is defined as:
I(E) = log_2 ( 1 / P(E) ) = - log_2 P(E)    (measured in bits).
Properties:
- If P(E) = 1 (an absolute certainty), I(E) = 0 bits: no information is gained by observing what was already certain.
- If P(E) -> 0 (an extremely rare event, such as a rare technical acronym), I(E) -> infty bits: observing the event conveys vast information.
- For independent events E_1 and E_2: I(E_1 cap E_2) = - log_2(P(E_1) * P(E_2)) = I(E_1) + I(E_2).

Definition 2.2 (Shannon Entropy H(X)):
Let X be a discrete random variable over a finite alphabet Sigma = {x_1, x_2, ..., x_n} with probability mass function P(X = x_i) = p_i.
The Shannon Entropy H(X) is the expected value of the self-information:
H(X) = E[I(X)] = - sum_{i=1}^n p_i * log_2(p_i).
By convention, if p_i = 0, then 0 * log_2(0) = lim_{p -> 0} p * log_2(p) = 0.

Theorem 2.1 (Maximum Entropy of Uniform Distributions):
For an alphabet of size n:
0 <= H(X) <= log_2(n).
The lower bound H(X) = 0 is achieved if and only if p_k = 1 for some k and p_i = 0 for all i != k (complete deterministic certainty).
The upper bound H(X) = log_2(n) is achieved if and only if X is uniformly distributed: p_i = 1 / n for all i = 1, 2, ..., n.

CHAPTER 3: RELATIVE ENTROPY (KULLBACK-LEIBLER DIVERGENCE) AND MUTUAL INFORMATION
Definition 3.1 (Kullback-Leibler Divergence D_{KL}):
The relative entropy between two probability distributions P and Q over alphabet Sigma measures the inefficiency of encoding events from P using a code optimized for Q:
D_{KL}(P || Q) = sum_{x in Sigma} P(x) * log_2 ( P(x) / Q(x) ).
Theorem (Gibbs' Inequality):
D_{KL}(P || Q) >= 0 for all distributions P and Q, with equality if and only if P == Q.

Definition 3.2 (Mutual Information I(X; Y)):
The mutual information between two random variables X and Y measures the reduction in uncertainty of X obtained by observing Y:
I(X; Y) = H(X) - H(X | Y) = sum_{x in X} sum_{y in Y} P(x, y) * log_2 ( P(x, y) / (P(x) * P(y)) ).
In digital library search ranking, mutual information between query terms and document subject headings determines optimal term expansion in semantic search.

CHAPTER 4: SHANNON'S NOISELESS CHANNEL CODING THEOREM
Theorem 4.1 (Source Coding Theorem):
Let a discrete memoryless source have entropy H(X).
Then a data sequence generated by this source can be compressed into a prefix-free binary code with an expected code word length L satisfying:
H(X) <= L < H(X) + 1.
No lossless compression scheme can compress the data to an expected length less than H(X) bits per symbol.
This theorem sets the theoretical upper bound on how compactly inverted index posting lists can be stored using Elias and Huffman compression.

CHAPTER 5: ALGORITHMIC DISPATCHING IN THE CO-1 SIGNATURE EVALUATOR
Within our digital library architecture, Claude Shannon's entropy calculation serves as the foundational metric for the CO-1 Problem-Class Signature Evaluator:
1. When a user submits text or a query, the system computes the empirical character entropy:
   H(S) = - sum_{c in Sigma} (count(c) / N) * log_2(count(c) / N).
2. If H(S) is low (H(S) < 2.5 bits), the text exhibits severe character repetition (e.g. genomic sequences, tabular numbers, or repetitive code blocks). In this regime, Boyer-Moore exhibits pathological degradation due to bad-character collisions, whereas KMP guarantees strict O(N) zero-rollback performance.
3. If H(S) is high (H(S) > 3.8 bits) and alphabet diversity is large, Boyer-Moore and Horspool achieve sublinear O(N / M) skips.
4. By dynamically evaluating Shannon entropy H(S), query ratio M/N, state space constraints, and bipartite matching requirements, the digital library query planner automatically delegates execution to the optimal algorithm from CO-1 through CO-4.
