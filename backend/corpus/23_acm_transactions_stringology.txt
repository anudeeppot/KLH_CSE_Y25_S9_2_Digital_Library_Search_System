Content: CHAPTER 1: THE SEARCH FOR THE MINIMAL SUBSTRING AUTOMATON
In full-text digital library search systems, the substring recognition problem is paramount: given a preprocessed document text T of length N, determine whether a query pattern P of length M appears anywhere within T.
A naive trie of all substrings requires O(N^2) states. A Suffix Tree achieves O(N) size but requires substantial memory overhead per node (storing pointers, edge indices, and suffix links).
In 1985, Anselm Blumer, Janet Blumer, David Haussler, and Maxime Crochemore independently introduced the Suffix Automaton (Directed Acyclic Word Graph - DAWG).
Definition 1.1 (The Suffix Automaton):
The Suffix Automaton of a string T is the minimal Deterministic Finite Automaton (DFA) that accepts the language of all substrings of T:
L(SAM) = { W in Sigma* : W is a substring of T }.
Because it is a minimal DFA, it provides the most compact graph representation possible for substring recognition. Once constructed, querying whether pattern P is a substring of T requires exactly M state transitions—strictly O(M) time, completely independent of the text length N!

CHAPTER 2: ALGEBRAIC DERIVATION: ENDPOS EQUIVALENCE CLASSES
The construction of the suffix automaton is based on the Myhill-Nerode theorem and the equivalence relation defined by end-positions.
Definition 2.1 (The Endpos Set):
For any non-empty string S, define endpos(S) as the set of all 0-based ending positions of occurrences of S in text T:
endpos(S) = { r : T[r - |S| + 1 .. r] = S }.
Example: In T = 'abracadabra', endpos('abra') = {3, 10}.
Definition 2.2 (The Right-Equivalence Relation equiv_{endpos}):
Two strings U and V are right-equivalent (U equiv_{endpos} V) if and only if endpos(U) = endpos(V).
Each equivalence class of strings sharing identical endpos sets corresponds to exactly one state in the suffix automaton!

Fundamental Properties of Endpos Classes:
Lemma 2.1 (Prefix Nesting):
Let U and V be two non-empty substrings of T with |U| <= |V|.
Then either:
1. endpos(U) cap endpos(V) = emptyset  (they never end at the same positions), or
2. endpos(V) subseteq endpos(U)  (and U is a suffix of V).
Proof:
If endpos(U) and endpos(V) share a common position r, then both U and V end at position r in T.
Since |U| <= |V|, U must be an exact suffix of V.
Therefore, wherever V appears in T, U must also appear ending at that identical position. Hence endpos(V) subseteq endpos(U).

Lemma 2.2 (The Suffix Link Tree):
For any state u in the automaton (except the root), let W be the shortest string in u's equivalence class.
The longest proper suffix of W that belongs to a different equivalence class belongs to a unique state v, called the suffix link of u:
link(u) = v.
The suffix links form a directed rooted tree (the Suffix Link Tree) oriented toward the initial state t_0. In fact, the Suffix Link Tree of text T is structurally isomorphic to the Suffix Tree of the reversed text T^R!

CHAPTER 3: LINEAR SIZE BOUNDS
Theorem 3.1 (State Bound):
For any string T of length N >= 1, the number of states |Q| in the Suffix Automaton satisfies:
|Q| <= 2N - 1.
Proof:
The initial state t_0 corresponds to the empty string epsilon, with endpos(epsilon) = {0, 1, ..., N - 1}.
As the text is built character by character, each appended character creates at most two states:
1. One state representing the newly created full prefix.
2. At most one state created by splitting an existing state when the transition condition violates maximal length continuity.
Starting with 1 state at N = 0, adding N characters introduces at most 2N states. For N >= 1, the bound is at most 2N - 1 states.

Theorem 3.2 (Transition Bound):
For any string T of length N >= 1, the number of directed edges (transitions) |delta| satisfies:
|delta| <= 3N - 4    (for N >= 3).
Proof:
Construct a spanning tree of the DAG starting from t_0. A spanning tree on |Q| vertices contains |Q| - 1 edges.
Each non-tree transition can be mapped to an equivalent distinct terminal path suffix. By topological sorting and DAG amortization, the total number of non-tree transitions is bounded by N - 1.
Combining with |Q| <= 2N - 1:
Total transitions <= (2N - 2) + (N - 1) = 3N - 3 (and bounded strictly by 3N - 4 for N >= 3).

CHAPTER 4: LINEAR-TIME O(N) INCREMENTAL CONSTRUCTION ALGORITHM
The automaton is constructed on-line by appending characters one by one.
Algorithm 1: SAM-Extend(character c)
1. Allocate new state cur with len(cur) = len(last) + 1.
2. Let p = last.
3. While p != -1 and p does not have a transition on c:
     delta(p, c) = cur
     p = link(p)
4. If p == -1:
     link(cur) = 0   // Link to root
5. Else:
     Let q = delta(p, c).
     If len(p) + 1 == len(q):
         link(cur) = q
     Else:
         // State split required
         Allocate clone state clone:
         len(clone) = len(p) + 1
         Copy transitions from q to clone: delta(clone, .) = delta(q, .)
         link(clone) = link(q)
         While p != -1 and delta(p, c) == q:
             delta(p, c) = clone
             p = link(p)
         link(q) = clone
         link(cur) = clone
6. last = cur.

CHAPTER 5: DIGITAL LIBRARY SEARCH PERFORMANCE
In our digital library search engine:
- The Suffix Automaton is built once per catalog document in O(N) time.
- Any pattern query of length M is answered in strictly O(M) time by traversing transitions from the root.
- The total distinct substrings of a document can be counted in O(|Q|) time via topological DFS on the automaton graph, enabling instant document complexity profiling.
