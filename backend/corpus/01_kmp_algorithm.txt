Title: Knuth Morris Pratt Pattern Matching
Author: Donald Knuth, James H. Morris, Vaughan Pratt
Category: String Algorithms
Year: 1977
ISBN: 978-0131103627
Type: Research Paper
Keywords: KMP, pattern matching, prefix function, LPS, string search, linear time
Abstract: The Knuth-Morris-Pratt algorithm solves the string matching problem in linear time by preprocessing the pattern into a Longest Proper Prefix which is also a Suffix (LPS) table, eliminating redundant comparisons upon mismatch.
Citations: 03_boyer_moore_search.txt, 04_suffix_array_indexing.txt
Content: Knuth Morris Pratt is a linear time string matching algorithm. It preprocesses a search pattern using the longest proper prefix that is also a suffix. The resulting LPS table allows the search to continue after a mismatch without restarting the pattern from the beginning. In the digital library project, KMP is used to locate a user query inside titles, authors, categories, keywords, and document content with guaranteed worst-case time complexity O(n + m) and auxiliary space O(m).
